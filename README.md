# AI augmentation systems for OpenAI

Distributable plugin source, tests and attribution for Codex-compatible hosts.

- [Delivery](plugins/delivery/README.md): product/feature planning and local helper preview.
- [Hook event log](plugins/hook-event-log/README.md): separate hook-event component.

Install from this repository's `.agents/plugins/marketplace.json` using the
host-supported plugin installation path. See each plugin's README for requirements
and current qualification limits. Package only the selected plugin directory.

## Product protection

Product IP, strategy, owner decisions and private project context belong in a
separate, verified private planning store. Permission to ship code never grants
permission to disclose that data. Unknown privacy/destination classification blocks
publication. Do not commit raw planning records, maps, transcripts or logs here.

Privacy remediation is in progress. Do not treat this history cleanup as proof
that the existing plugin enforces private-planning/publication protection. That
separate repair requires verification before real private-product use.

Each plugin retains its licence, notices and pinned source attribution.
